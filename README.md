# Sales-Analysis-Dashboard


## Overview

Interactive sales analysis dashboard developed using Microsoft Power BI to analyze revenue, profit and sales performance across different dimensions.

## Key Analysis

- Monthly Revenue and Profit Analysis
- Customer Analysis
- Seller Performance Analysis
- Product Category Analysis
- Sales Analysis by Gender
- Sales Analysis by Age Group
- Product-level analysis

## Key Features

- Interactive slicers and filters
- KPI cards
- Revenue and Profit analysis
- Category-level analysis
- Customer and seller analysis
- Interactive data visualizations

## Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
